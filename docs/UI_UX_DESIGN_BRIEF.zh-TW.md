# LatticeTerm UI/UX 設計規格書

文件版本：1.0  
更新日期：2026-08-20  
適用平台：Windows、Linux、macOS 桌面應用程式  

---

## 1. 產品定位與設計原則

LatticeTerm 是一套專為開發者與系統維運人員打造的安全、高效率且跨平台的遠端連線工作空間，整合 SSH、SFTP、RDP、VNC、SSH Tunnel 與 Key Vault。

### 設計核心原則

- **專業與冷靜**：以深色為基底的高對比工作環境，長時間使用不易視覺疲勞。
- **資訊密度高但不擁擠**：提供 Comfort 與 Compact 兩種密度模式，滿足大量伺服器管理需求。
- **鍵盤優先（Keyboard-First）**：所有核心操作（搜尋、建立、切換檢視、執行動作）皆可透過鍵盤或 Command Palette 完成。
- **透明的安全狀態**：清晰呈現連線協定、目標主機、認證狀態與環境標記（Production / Staging / Development），杜絕誤操作。
- **誠實反饋**：明確區分已就緒功能與規劃中項目（Planned），絕不使用無效的假按鈕誤導使用者。

---

## 2. 目標使用者與情境

1. **工程師與開發者**：管理開發機、測試伺服器與家用主機，重視快速搜尋、分頁切換與工作階段重連。
2. **維運／SRE 人員**：管理大規模正式伺服器，需要多層群組、標籤檢索、環境隔離標記、Tunnel 轉送與主機指紋嚴格比對。
3. **遠端圖形桌面使用者**：透過 RDP 或 VNC 進行圖形化管理，需要高可視面積、縮放支援與明確的輸入捕捉/釋放提示。

## 3. 資訊架構與版面規劃

桌面版採用「全域導覽 + 資源側欄 + 彈性工作區 + 狀態列」的標準框架：

| 介面區域 | 元件與尺寸 | 功能說明 |
|---|---|---|
| **全域導覽列** (Nav Rail) | 56 px 固定寬度 | 提供 Connections、Tunnels、Key Vault、Activity、Settings 一級導覽與主題切換。 |
| **資源側欄** (Sidebar) | 280 px（可收合） | 提供即時搜尋（`/` 聚焦）、群組導覽、環境標籤與常用篩選。可用 `Ctrl` + `B` 收合。 |
| **工作區標頭** (Header) | 彈性寬度 | 顯示當前檢視標題、說明與主要動作（如新增連線、匯出/匯入等）。 |
| **主工作區** (Workspace) | 彈性寬度 | 呈現連線清單、終端機分頁或圖形桌面。 |
| **連線檢視側欄** (Inspector)| 320 px（可展開） | 選取連線後於右側顯示目標詳細資訊、環境標記與快捷動作。 |
| **狀態列** (Status Bar) | 28 px 底部狀態列 | 即時回報連線數量、儲存模式、Vault 鎖定狀態與快捷鍵指引。 |

## 4. 核心功能規格

### 4.1 連線管理 (Connections)
- **清單與分組**：依群組分區呈現，常用釘選（Favorite）置頂顯示。
- **快速搜尋與過濾**：支援多關鍵字搜尋（主機名、IP、使用者、群組、標籤）與 Facet 交叉篩選。
- **安全匯出與匯入**：支援標準 JSON 格式的非機密設定匯出與匯入，匯入時自動執行結構與格式檢驗。
- **新增/編輯抽屜 (Drawer)**：分段式表單（Protocol、Target、Organisation、Authentication、Review），具備即時錯誤校驗與重複目標警示。

### 4.2 活動紀錄 (Activity)
- **活動追蹤**：記錄連線設定的建立、更新、刪除與匯入操作。
- **搜尋與篩選**：支援依關鍵字搜尋及依事件類型（新增、更新、刪除、工作區）過濾。
- **安全匯出**：支援匯出純文字或 JSON 診斷日誌，保證絕不記錄任何密碼、私鑰或敏感指令輸出。

### 4.3 命令面板 (Command Palette)
- 透過 `Ctrl` + `K` 隨時喚起，支援模糊搜尋連線目標、功能切換、外觀設定（主題/密度）與全域動作。

### 4.4 安全與信任流程 (Security & Trust)
- **未記錄主機指紋**：連線前彈出指紋確認對話框，顯示完整 SHA-256 指紋與演算法，提供「僅本次信任」與「信任並儲存」選項。
- **主機金鑰變更警告**：檢測到金鑰變更時觸發阻擋式高風險警告，對比新舊指紋，防止中間人攻擊（MITM）。
- **非機密性保證**：連線 Profile 僅保存主機與組織中繼資料；明確保存的密碼由系統金鑰庫或主密碼加密保管庫管理，SSH 私鑰只從使用者選擇的本機路徑使用且不複製；加密保管庫支援手動鎖定，以及可調整期限的全域閒置與背景自動鎖定。

## 5. 設計 Token 與無障礙標準

- **主題架構**：深色為預設（Dark-first），透過 CSS 變數無縫支援淺色主題（Light）與系統偏好跟隨。
- **無障礙目標**：嚴格遵循 WCAG 2.2 AA 規範，一般文字色彩對比達 4.5:1 以上。
- **全鍵盤可用**：焦點指示環（Focus Ring）獨立清晰，抽屜與彈窗具備 Tab 循環與 Esc 關閉支援。
- **圖示規範**：全站圖示採 16px 網格與 1.5px 線寬自行繪製，不依賴第三方外部圖示庫，不使用 Emoji 作為功能圖示。
