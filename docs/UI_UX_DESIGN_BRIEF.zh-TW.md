文件版本：1.2

適用平台：Windows、Linux、macOS 桌面應用程式  

---

## 1. 產品定位與設計原則

LatticeTerm 是一套專為開發者與系統維運人員打造的安全、高效率且跨平台的終端與遠端連線工作空間，整合本機 AI Agent Fleet、SSH、SFTP、Lattice Remote、Web RDP、VNC、SSH Tunnel 與 Key Vault。

### 設計核心原則

- **專業與冷靜**：以深色為基底的高對比工作環境，長時間使用不易視覺疲勞。
- **資訊密度高但不擁擠**：提供 Comfort 與 Compact 兩種密度模式，滿足大量伺服器管理需求。
- **鍵盤優先（Keyboard-First）**：所有核心操作（搜尋、建立、切換檢視、執行動作）皆可透過鍵盤或 Command Palette 完成。
- **透明的安全狀態**：清晰呈現連線協定、目標主機、認證狀態與環境標記（Production / Staging / Development），杜絕誤操作。
- **誠實反饋**：明確區分已就緒功能與規劃中項目（Planned），絕不使用無效的假按鈕誤導使用者。

## 2. 目標使用者與情境

1. **工程師與開發者**：管理開發機、測試伺服器與家用主機，重視快速搜尋、分頁切換與工作階段重連。
2. **維運／SRE 人員**：管理大規模正式伺服器，需要多層群組、標籤檢索、環境隔離標記、Tunnel 轉送與主機指紋嚴格比對。
3. **遠端圖形桌面使用者**：透過 RDP 或 VNC 進行圖形化管理，需要高可視面積、縮放支援與明確的輸入捕捉/釋放提示。
4. **AI CLI 使用者**：同時操作多個本機大型語言模型 CLI，需要原生 PTY、狀態回報、批次提示、Session 續接與可重建的啟動工作區。

## 3. 資訊架構與版面規劃

桌面版採用「全域導覽 + 資源側欄 + 彈性工作區 + 狀態列」的標準框架：

| 介面區域 | 元件與尺寸 | 功能說明 |
|---|---|---|
| **全域導覽列** (Nav Rail) | 56 px 固定寬度 | 提供 Connections、Sessions、Agent Fleet、Tunnels、Key Vault、Activity、Settings 一級導覽與主題切換。 |
| **資源側欄** (Sidebar) | 280 px（可收合） | 提供即時搜尋（`/` 聚焦）、群組導覽、環境標籤與常用篩選。可用 `Ctrl` + `B` 收合。 |
| **工作區標頭** (Header) | 彈性寬度 | 顯示當前檢視標題、說明與主要動作（如新增連線、匯出/匯入等）。 |
| **主工作區** (Workspace) | 彈性寬度 | 呈現連線清單、終端機分頁或圖形桌面。 |
| **連線檢視側欄** (Inspector)| 344 px（可展開） | 選取連線後於右側顯示目標詳細資訊、環境標記與快捷動作。 |
| **狀態列** (Status Bar) | 28 px 底部狀態列 | 即時回報連線數量、儲存模式、Vault 鎖定狀態與快捷鍵指引。 |

## 4. 核心功能規格

### 4.1 連線管理 (Connections)
- **清單與分組**：依群組分區呈現，常用釘選（Favorite）置頂顯示。
- **快速搜尋與過濾**：支援多關鍵字搜尋（主機名、IP、使用者、群組、標籤）與 Facet 交叉篩選。
- **安全匯出與匯入**：支援標準 JSON 格式的非機密設定匯出與匯入，匯入時自動執行結構與格式檢驗。
- **新增/編輯抽屜 (Drawer)**：分段式表單（Protocol、Target、Organisation、Authentication、Review），具備即時錯誤校驗與重複目標警示。

### 4.2 活動中心 (Activity)
- **CLI 工作追蹤**：鈴鐺集中顯示未讀、執行中、等待使用者回覆與已完成的 CLI 工作，未讀數直接顯示於全域導覽列。
- **返回工作**：選取仍開啟的活動會切回對應 CLI 工作階段；查看中的分頁會自動標為已讀，也可一次將全部活動標為已讀。
- **跨重啟保存**：有界保存最多 100 筆工作階段名稱、CLI、資料夾、狀態與時間，不保存提示、終端輸出、認證或供應商 Token；初次載入不會把舊狀態誤算成新通知。
- **鍵盤操作**：Windows/Linux 使用 `Ctrl` + `Alt` + `U`，macOS 使用 `Cmd` + `Option` + `U` 開關活動中心。
- **操作紀錄**：同頁保留連線設定建立、更新、刪除與匯入的本次視窗日誌，支援關鍵字搜尋、事件類型篩選與安全純文字匯出。

### 4.3 命令面板 (Command Palette)
- 透過 `Ctrl` + `K` 隨時喚起，支援模糊搜尋連線目標、功能切換、外觀設定（主題/密度）與全域動作。

### 4.4 安全與信任流程 (Security & Trust)
- **未記錄主機指紋**：連線前彈出指紋確認對話框，顯示完整 SHA-256 指紋與演算法，提供「僅本次信任」與「信任並儲存」選項。
- **主機金鑰變更警告**：檢測到金鑰變更時觸發阻擋式高風險警告，對比新舊指紋，防止中間人攻擊（MITM）。
- **非機密性保證**：連線 Profile 僅保存主機與組織中繼資料；明確保存的密碼由系統金鑰庫或主密碼加密保管庫管理，SSH 私鑰只從使用者選擇的本機路徑使用且不複製；加密保管庫支援手動鎖定，以及可調整期限的全域閒置與背景自動鎖定；複製的一次性配對碼由摘要追蹤並在內容仍相符時自動清除。
- **完整工作區備份**：設定頁提供密碼保護的加密匯出與還原；介面必須明列包含／排除範圍、要求保管庫鎖定、在取代目前資料前再次確認，且不得把明文 payload 寫入下載或暫存檔。

### 4.5 AI Agent Fleet
- **本機原生 PTY**：桌面版以目前作業系統使用者權限同時啟動多個 CLI；可執行檔與參數分離傳遞，不經 shell 拼接。
- **偵測與安裝**：未偵測到 CLI 時先呈現固定安裝指令及來源，經使用者確認後在可見終端執行；無法安全直接安裝的平台則提供上游說明網址。
- **名稱與模型**：分頁名稱不覆蓋 CLI 名稱；切換列同時顯示 CLI 與其明確回報的模型，無可靠資訊時標成尚未回報。
- **狀態與協作**：呈現 heuristic 或 Reporter 回報的工作狀態；批次提示必須先選定執行中的目標並再次確認。
- **續接與重建**：執行中分頁可加開另一個 CLI，並在支援的來源間帶入目前對話；另提供可命名排序的安全啟動工作區，以及同一桌面程序內 WebView 重載後的 PTY 重新 attach。不得宣稱應用程式重啟後舊程序仍存活。

### 4.6 圖形與遠端工作階段
- **Lattice Remote**：由被控端使用者明確啟動，以八位數配對碼與 Noise 端對端加密分享完整主螢幕或純終端；可選區網直連，或經自架中繼以九位數裝置 ID 連線。預設唯讀，鍵鼠／終端輸入與單一檔案根目錄必須分開授權；中繼位址記住後收合只是簡化日常介面，不宣稱為機密。
- **Web RDP 與 VNC**：以隔離 sidecar 將畫面繪入內嵌 Canvas；RDP 支援 TLS／NLA 與完整輸入，傳統 VNC 必須明示未加密並建議搭配 SSH Tunnel。
- **擷取控制**：截圖與錄影只能由使用者手動開始，媒體先留在 WebView 記憶體，除非使用者下載，否則不寫入應用程式資料或上傳。

## 5. 設計 Token 與無障礙標準

- **主題架構**：深色為預設（Dark-first），透過 CSS 變數提供深色、淺色、午夜藍、石墨黑、暖砂與高對比六種主題，另可跟隨系統偏好。
- **無障礙目標**：嚴格遵循 WCAG 2.2 AA 規範，一般文字色彩對比達 4.5:1 以上。
- **全鍵盤可用**：焦點指示環（Focus Ring）獨立清晰，抽屜與彈窗具備 Tab 循環與 Esc 關閉支援。
- **圖示規範**：全站圖示採 16px 網格與 1.5px 線寬自行繪製，不依賴第三方外部圖示庫，不使用 Emoji 作為功能圖示。
