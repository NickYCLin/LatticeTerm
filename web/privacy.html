LatticeTerm iOS 隱私權政策

更新日期：2026-09-05

LatticeTerm 是連接使用者自有或經授權主機的遠端工具。本政策說明 iOS App 的資料使用方式。

裝置上的資料

連線設定、偏好設定、操作紀錄與保管庫儲存在裝置上。你選擇保存的認證資料由本機加密保管庫或 iOS Keychain 管理。App 不內建廣告、使用分析或跨 App 追蹤。

你指定的主機與服務

使用 SSH、SFTP 或遠端連線時，登入資料、指令與檔案會依你的操作傳往指定主機。若使用自選中繼，中繼可能取得連線所需的網路資訊。這些主機與服務的資料處理由其管理者及政策決定。

權限與功能需要

區域網路權限用來連接你指定的區網主機。App 依你的操作存取選取的檔案與剪貼簿，並讀取本機檔案中繼資料、使用計時器完成檔案傳輸與連線逾時等功能。

資料管理

你可以在 App 管理連線與已儲存的認證資料。解除安裝會移除 App 容器資料，但 Keychain 項目與另行匯出的備份可能保留，請另外管理。系統備份的保存方式也受你的 Apple 裝置設定影響。

問題回報與測試

GitHub 會接收你主動提交的問題回報。公開回報前請移除密碼、私鑰、個人主機位址及其他敏感資訊。TestFlight 的診斷與回饋另依 Apple 的機制處理。本支援網站由 GitHub Pages 提供，主機服務可能處理一般網路存取資訊。

聯絡

隱私與使用問題可透過 LatticeTerm 專案問題回報聯絡維護者；請勿在公開 issue 提交敏感資料。
